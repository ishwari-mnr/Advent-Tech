# Advent-Tech

A prototype of the Advent-Tech website: a landing page, a sign-in page and a "Coming Soon" page after login.

## Getting started

Requires Node.js 18 or later.

```bash
npm install
npm start
```

The app opens at http://localhost:3000.

To create a production build in `./build`:

```bash
npm run build
```
